## <span style="color:#E10600">Sobre o projeto</span>

A **MinhaLoja** é um projeto de e-commerce full stack desenvolvido para aplicar conceitos de interface, APIs, banco de dados, autenticação e testes. O foco inicial foi implementar a lógica e integrar as funcionalidades; a interface continua em evolução.

## Funcionalidades

- Catálogo de produtos com pesquisa e filtro por categoria
- Página de detalhes dos produtos
- Carrinho persistente no navegador
- Checkout simulado, sem cobrança real
- Autenticação e histórico de pedidos
- Painel administrativo com gestão de produtos e pedidos
- Dashboard com indicadores de vendas

## Como executar

```bash
npm install
cp .env.example .env
npm run db:push
npm run db:seed
npm run dev
```

Configure as variáveis necessárias em `.env`, conforme o arquivo `.env.example`, e acesse `http://localhost:3000`. Para testes: `npm run test` e `npm run test:e2e`.
